# Supplementary Figure S1: Web-Based Screening Tool

The screenshots in this directory were generated from web application version `1.1.2` using only the synthetic records in `examples/sample_input.csv`. They contain no participant or clinical-study data.

The screenshots are incorporated into the illustrated `USER_GUIDE.md` and the submission-ready `output/pdf/USER_GUIDE_v1.1.2.pdf` user manual.

- `Figure_S1A_screening_interface.png`: batch-screening landing interface, intended-use statement, safety warning, and required columns.
- `Figure_S1B_batch_results.png`: synthetic batch-screening results, screening summary, model scores, classifications, and recommended actions.
- `Figure_S1C_how_to_use.png`: intended users, recommended workflow, PDF user-manual download, training requirements, input definitions, and interpretation guidance.
- `Figure_S1D_model_information.png`: model and application versions and technical implementation details.
- `Figure_S1E_temporal_validation_performance.png`: temporal-validation estimates and 95% confidence intervals.
- `Figure_S1F_governance.png`: intended and prohibited uses, privacy, version control, monitoring, and clinical responsibility.

Suggested caption:

> Supplementary Figure S1. Interface of the web-based sarcopenia screening tool. (A) Batch-screening landing page and required input format. (B) Screening output generated using synthetic demonstration records, including model scores, screening classifications, and recommended actions. (C) User guidance and recommended workflow. (D) Model and web-application version information and technical implementation details. (E) Temporal-validation performance of the locked final model. (F) Governance, privacy, monitoring, and clinical-responsibility information. The demonstration records contain no participant data.
